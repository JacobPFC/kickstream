KickStream API

A free, edge-cached REST API for movie and TV show data. Built on Cloudflare Workers — fast responses from 300+ locations globally. Powered by TMDB.

Base URL https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api
100Kreq / day free
300+edge locations
0mscold start
CORSenabled
JSONonly
Quickstart
Get trending movies in under 30 seconds. No sign-up required for open access.
// Get trending movies
const res = await fetch('https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api/trending?type=movie');
const data = await res.json();
console.log(data.results); // array of movie objects

// Search for a title
const search = await fetch('https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api/search?q=inception&type=movie');
const results = await search.json();

// Get embed sources for a movie (TMDB id: 27205)
const sources = await fetch('https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api/sources/movie/27205');
const { sources: srcs } = await sources.json();
console.log(srcs[0].url); // embed URL ready to drop into an iframe
import axios from 'axios';

const api = axios.create({
  baseURL: 'https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api',
});

// Trending TV shows
const { data } = await api.get('/trending', { params: { type: 'tv' } });
console.log(data.results);

// Movie details
const { data: movie } = await api.get('/movie/550'); // Fight Club
console.log(movie.title, movie.vote_average);
import requests

BASE = "https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api"

# Trending movies
r = requests.get(f"{BASE}/trending", params={"type": "movie"})
movies = r.json()["results"]

# Search
r = requests.get(f"{BASE}/search", params={"q": "inception", "type": "all"})
results = r.json()["results"]

# Embed sources

sources = r.json()["sources"]
print(sources[0]["url"])  # drop into an <iframe>
Authentication
The API is open by default. The owner can optionally enable key-based auth.
ℹ️ If the API owner has set a PUBLIC_API_KEY secret on the Worker, you'll need to include it with every request. Otherwise no auth is required.

Pass your key via query param or request header:

// Query param
fetch('https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api/trending?type=movie&key=YOUR_API_KEY')

// Header (preferred)
fetch('https://kickstream-api.YOUR-SUBDOMAIN.workers.dev/api/trending?type=movie', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' }
})

Stream Sources
Returns all embed URLs for a title — ready to drop into an iframe. This is the unique endpoint you won't find in a standard TMDB wrapper.
GET /sources/:type/:id All embed sources for a movie ▼
ParamTypeRequiredDescription
:typestringrequiredmovie or tv
:idnumberrequiredTMDB ID
GET /api/sources/movie/27205
{
  "id": "27205",
  "type": "movie",
  "sources": [
    { "name": "VidKing", "url": "https://www.vidking.net/embed/movie/27205" },
    { "name": "Aiden", "url": "https://vidsrc.cc/v3/embed/movie/27205" },
    // ... 6 more sources
  ]
}
⚠️ Source URLs are not cached — they're generated fresh each request. Availability of each source may vary.

Usage in a web page

const { sources } = await fetch('/api/sources/movie/27205').then(r => r.json());
const iframe = document.getElementById('player');
iframe.src = sources[0].url; // use VidKing first
